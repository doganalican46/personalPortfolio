# Personal Portfolio Website

Ali Can Doğan'ın yazılım projelerini, teknik yetkinliklerini ve iletişim bilgilerini sunan iki dilli kişisel portfolyo sitesi.

Canlı site: [doganalican46.dev](https://www.doganalican46.dev/)

## Özellikler

- Türkçe ve İngilizce içerik desteği
- Web, Android ve masaüstü proje filtreleri
- EmailJS ile çalışan iletişim formu
- Türkçe ve İngilizce CV indirme bağlantıları
- Mobil uyumlu, klavye ile kullanılabilir arayüz
- Hareket azaltma tercihi ve temel erişilebilirlik desteği

## Dosya yapısı

```text
.
├── index.html          # Ana sayfanın semantik yapısı
├── orbitdash.html      # Orbit Dash gizlilik politikası
├── css/
│   ├── site.css        # Siteye özel tüm stiller
│   └── font-awesome.min.css
├── js/
│   ├── app.js          # Menü, dil, filtre ve form davranışları
│   ├── i18n.js         # Türkçe ve İngilizce arayüz metinleri
│   └── projects.js     # Proje verileri
├── images/             # Profil ve proje görselleri
├── cv/                 # İndirilebilir CV dosyaları
└── webfonts/           # Font Awesome yazı tipi dosyaları
```

## Yerelde çalıştırma

Proje derleme adımı gerektirmez. Klasörü herhangi bir statik dosya sunucusuyla açabilirsiniz. Örneğin VS Code Live Server kullanılabilir.
